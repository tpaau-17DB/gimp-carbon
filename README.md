# Installation

### Windows
Copy the CSS under `3.0` to `C:\Users\your_user\AppData\Local\Programs\GIMP 3\share\gimp\3.0\themes\Default\`

### Linux

#### Standard GIMP
```
cp 3.0/common-dark.css 3.0/gimp-dark.css /usr/share/gimp/3.0/themes/Default/
```

#### GIMP flatpak

##### System installation
```
cp 3.0/common-dark.css 3.0/gimp-dark.css /var/lib/flatpak/app/org.gimp.GIMP/current/stable/active/files/share/gimp/3.0/themes/Default/
```

##### User installation
```
cp 3.0/common-dark.css 3.0/gimp-dark.css ~/.local/share/flatpak/app/org.gimp.GIMP/current/active/files/share/gimp/3.0/themes/Default/
```
